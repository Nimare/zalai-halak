# Quiz result stickers

The five original PNG stickers were supplied by the site owner for the quiz
results on 1 October 2026. They are stored locally with the site's other static
assets and served from `/stickers/`.

- `lapi-poc.png`: Lápi póc
- `folyami-geb.png`: Folyami géb
- `ponty.png`: Ponty
- `suger.png`: Sügér
- `csuka.png`: Csuka

The corresponding descriptions in `data/quiz-results.json` come from
[Téli FT 2027 ZALAI HALAK](https://docs.google.com/document/d/1sFI1BtulWm_C1pvKseJFm4gRFAwH6VvSXgKyGpGjneQ/edit).
Original wording and paragraph boundaries are preserved.
